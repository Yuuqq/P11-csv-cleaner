## 🎓 教学使用说明

> 本工具是《新闻传播AI应用教程》（中国人民大学出版社）配套在线实验平台工具，属于**篇Ⅱ 方法篇 · 第5章 新闻数据的获取与管理**（教材 Tier 1 实验工具）。教材命名："CSV 洗表机"。

**学习目标**：掌握数据清洗的基本动作（去重、缺失值处理、结果核验），树立"数据入稿前必须洗表、涉个人信息先脱敏"的数据管理规范。

**核心术语**：数据清洗（Data Cleaning）、数据脱敏（Data Anonymization）、缺失值（Missing Value）

**适合对象**：新闻传播专业学生、数据新闻初学者、媒体从业者

**课前准备**：课前向教师领取（或自行准备）一份含重复行与空值的 CSV 练习数据（如读者调查表、公开账目表）；本工具打开即用、离线可用，数据不离开浏览器。

**课堂流程建议（40 分钟，符合教材"单工具课堂可完成"标准）**
1. **演示导入**（8 分钟）：教师拖入一份埋了重复行与空值的调查 CSV，执行"去重（按整行）"与"空值填补（数值列填 0）"，对照清洗前后的表格预览、图表与行数变化，讲解每一步在"洗"什么
2. **上手实操**（20 分钟）：学生按教材实验步骤完成：①把自己的 CSV 拖入工具，通过表格预览盘点问题（重复行数、空值分布、异常值）；②勾选去重与空值填补后点击"执行清洗"；③对照图表预览核查清洗是否引入失真；④手动删除或遮盖姓名、手机号等身份字段，完成数据脱敏；⑤点击"导出清洗后 CSV"，并记录清洗日志（每步做了什么、为什么）
3. **小组讨论**（8 分钟）：把"空值一律填 0"用在这份表里会不会扭曲结论？哪些字段在公开发布前必须脱敏？
4. **总结**（4 分钟）：清洗每一步都要留痕可复现，脱敏必须在导出之前完成

**课后作业**：对一份真实公开数据集完成清洗与脱敏，提交"原始表＋清洗后表＋清洗日志（步骤与理由）"三件套

**评价建议**：实操完成度 40% · 分析深度 40% · 反思质量 20%

> 🔒 本工具所有数据仅在浏览器本地处理，课堂与机房环境可放心使用（支持离线）。
